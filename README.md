**Jarco Engine** — это обязательный системный плагин, обеспечивающий работу с данными, мета-полями и кастомной логикой для всех проектов группы компаний Jarco.

## Ключевые возможности
- **WooCommerce Enhancements:** Кастомные поля для вариативных товаров (состав, энергия, жиры, белки).
- **Auto-updates:** Интеграция с GitHub для автоматического обновления на всех сайтах сети.
- **Admin Optimization:** Управление колонками в админке и кастомные стили для удобства контент-менеджеров.
- **Taxonomy Tools:** Расширенные поля для атрибутов товаров (например, `pa_lineika`).

## Установка
1. Клонируйте репозиторий в папку `/wp-content/plugins/jarco-engine/`.
2. Активируйте плагин в админ-панели WordPress.
3. Убедитесь, что установлена библиотека `Plugin Update Checker` (включена в состав).

## Структура проекта
- `/inc` — ядро (библиотека обновлений, конфигурация).
- `jarco-engine-meta-boxes.php` — логика регистрации всех мета-полей.
- `jarco-engine.php` — основной файл инициализации и хуков.
